# MDC-0007 - Builder Integration

## Goal

Integrate Builder AI into Menezes Developer Console.

## Command

mdc builder hero-video

## Flow

1. Detect Git repository.
2. Detect current project.
3. Verify clean working tree.
4. Verify current branch.
5. Create feature branch.
6. Generate Builder prompt.
7. Copy prompt to clipboard.
8. Open Builder project.
9. Wait for PR.
10. Validate changed files.
11. Merge.
12. Pull.
13. Cleanup.

## First supported project

menezes-pro

## Status

Draft
