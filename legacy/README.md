# Legacy Module

Este directorio conserva la implementación original del
GitHub Manager desarrollado durante la construcción del
sitio menezes.pro.

Fecha de archivado:
2026-07-11

Motivo:

GitHub Desktop cubre de forma nativa las funciones de:

- Commit
- Push
- Pull
- Branches
- Merge
- Pull Requests
- History

Por esta razón el proyecto evoluciona hacia:

MENEZES DEVELOPER CONSOLE (MDC)

que será la consola de operaciones completa de menezes.PRO.

El código se conserva únicamente como referencia histórica.
